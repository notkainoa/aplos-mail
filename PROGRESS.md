## 2026-10-15 — M24 local mail engine foundation

Started the multi-provider plan (see DECISIONS.md, "Multi-provider, serverless architecture"). Added `src/engine/` with platform-free pieces: a minimal synchronous SQL port (`sql.ts`), the mailbox store (`store.ts`: schema with `user_version` migrations, accounts/threads/drafts/events/conversations/meta tables, per-account sync cursors and an FTS5 index over subject, people and text), the provider contract (`provider.ts`: changed threads, flag-only updates, removals, next cursor, reset), workflow-preserving merge rules (`merge.ts`) and a per-account sync gate (`gate.ts`). The desktop adapter (`src/main/store.ts`) backs the port with Node's built-in `node:sqlite` in WAL mode, so Electron needs no native rebuild, and imports an existing `state.json` once, keeping it as `state.json.imported` (a damaged file still produces a recovery copy). The store writes only rows that changed since the last save, in one transaction, and its snapshot only advances after commit.

Gmail now syncs incrementally: the first sync reads the profile `historyId` and then the newest 500 threads; later syncs follow `history.list` (added/deleted messages and label changes, paged, at most 20 pages). ## 2026-10-15 — M25 durable operation queue and safe send

Gmail triage is now local-first. `thread.update`, `thread.undo` and reminders change the thread at once and, in the same SQLite transaction, add a provider change to a new `ops` table (schema v2). A worker sends ops in order per account and holds back that account's later ops when one fails, retrying after 30 s doubling to 15 min. "Sync now" retries at once, and a 404 drops the op because the thread is gone. Sync sends queued ops before it pulls, and threads with an op still queued keep their local status, read state, star and labels, so a pull can no longer undo what you just did. Disconnecting an account drops its ops.

Sending can no longer go out twice. Each draft gets one Message-ID on the sender's domain at its first send, kept for retries; `sendAttemptAt` is saved before Gmail is called.
