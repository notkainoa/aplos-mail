# Improve audit: findings and plans

Generated by the `improve` skill (shadcn/improve) on 2026-11-11 against
`revamp` at commit `8a254600`. Audit only: nothing here is implemented. The
owner picks which plans to run; each plan is self-contained for a cheaper
executor model and carries its own verification gates and STOP conditions.

This folder is separate from the repo's own design docs in `plans/`. Nothing
else in `plans/` was changed.

## In plain English

The code is in better shape than most audits find. Sync, sending and
security hardening on the new engine held up under a close read. The problems
that matter are concentrated in three places:

1. **Opening an email.** Besides the bug already being fixed elsewhere, a few
   smaller causes can still make emails slow or show "Couldn't load this email",
   especially after Gmail asks Aplos to slow down. These are written up as notes
   for the thread fixing it (`reader-load-notes.md`), not as separate plans.
2. **The app you can download today** still uses the old reader, and it lets
   tracking images inside SVG through even with images off. That is a
   one-file fix (plan 001).
3. **Small UI gaps.** Long lists can't be scrolled past 200 rows with a mouse
   (plan 002), and a couple of failures show nothing (plan 003).

## Direction (options, not problems)

- **Go-live and the legacy stack.** Release builds still ship the legacy
  renderer and engine (`apps/desktop/src/host/transports/port.ts:63-65`); about
  26k lines (`renderer/legacy`, `engine/src/legacy`) plus the `main/*`
  adapters stay alive and must stay green until the switch. Every legacy
  finding above disappears with it. The roadmap already names this as the
  remaining owner step (`plans/00-roadmap.md`, `plans/HAND-CHECK.md`); the
  trade-off is that IMAP, JMAP and Outlook live only in the legacy adapters
  today, so the cutover must decide what happens to those accounts.
- **Coordination docs as agent cost.** `plans/STATUS.md` (2,800+ lines),
  `DECISIONS.md` (2,000) and `PROGRESS.md` (700) are read at the start of many
  sessions (`TODO.md` asks for it). Rotating STATUS/DECISIONS monthly into an
  archive and keeping a short "current state" file would cut orientation cost
  for every thread. Owner/integrator call; no plan written.

## Findings considered and rejected

- **Release reader renders mail in the privileged page (legacy `dangerouslySetInnerHTML`).** Real, but the fix is the sealed frame the real engine already ships; go-live is the remedy. Plan 001 closes the concrete leak meanwhile.
- **Legacy "Load images" uses the default session (tracker cookies).** Deferred into plan 001's maintenance notes; retires at go-live.
- **Dev preview API (`src/main/server.ts`) has no token.** Loopback-only, Host-checked, dev-only. Low value.
- **`disable-library-validation` / `allow-unsigned-executable-memory` entitlements.** Already tracked by a comment in `build/entitlements.mac.plist` asking for a signed experiment; needs a signed build on a second Mac.
- **`commits` table grows forever; `ageFloor` scans it.** Documented trade-off (`DECISIONS.md` ~444); growth is slow. Revisit if compaction shows up in traces.
- **Gmail sweep loads all stale placement rows at once (`commit-sync.ts:39-55`).** LOW confidence; window bounds may keep it small. Investigate only with a real database.
- **Per-row `summaries`/`folderIds` lookups in list rows.** Local point reads; small.
- **List rows not memoized.** Unprofiled; noted in plan 002's maintenance notes.
- **Compose effect queue swallows errors (`compose/runtime/session.ts:123-125`).** LOW confidence; every effect checked has its own failure path.
- **Focus-ring suppressions in CSS.** Unverified pattern; most pair with a replacement indicator.
- **CI has no `pull_request` trigger.** Deliberate free-minutes rule stated in `.github/workflows/ci.yml:3-5`; local CI is the gate.
- **Dependency pinning mixes `^` and exact versions.** Lockfile is authoritative; low value.
- **Engine core byte budget nearly full.** A recorded owner decision (`budgets.json` notes); the cost is review overhead, not a defect.
